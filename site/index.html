WHAT IT DOES

완성 영상 하나로 끝내지 않아요

01

장면을 읽고 컷 편집

영상 길이와 장면 흐름을 보고 주요 구간을 고른 뒤, 숏폼 화면에 맞는 편집 초안을 구성합니다.

02

자막·음악은 별도 레이어

CapCut에서 문구와 타이밍을 직접 고칠 수 있도록 자막과 지원되는 오디오 요소를 분리해 전달합니다.

03

내 기기에서 이어서 작업

소스 영상과 결과물은 각 사용자 컴퓨터에 보관됩니다. 프로젝트를 열어 확인하고 마무리하세요.

HOW IT WORKS

세 단계로 CapCut까지

  1. 1로컬 앱 실행이 컴퓨터에 앱과 필요한 도구를 설치합니다.
  2. 2영상 선택 후 초안 생성영상 처리와 작업 데이터는 로컬에 남습니다. AI 기능은 본인 API 키와 별도 사용료가 필요합니다.
  3. 3CapCut에서 검토·마무리생성된 편집 프로젝트를 열어 컷과 자막을 직접 다듬습니다.

COMPATIBILITY

다운로드 전에 확인해 주세요

macOS

Intel·Apple Silicon 네이티브 패키지의 CI 실행·화면·합성 렌더 검증을 통과했습니다. 일반 사용자 Mac의 설치, FFmpeg 준비, 서명·공증과 CapCut 확인은 아직 남았습니다.

패키지 CI 통과 · 정식 배포 전

Windows

x64 패키지와 사용자별 설치·실행·제거가 CI에서 통과했습니다. 일반 사용자 PC의 설치, FFmpeg 준비와 CapCut 프로젝트 호환성은 아직 확인되지 않았습니다.

패키지 CI 통과 · 정식 배포 전

CapCut과 FFmpeg/FFprobe는 별도 구성요소입니다. CapCut 버전, 템플릿, 코덱 및 컴퓨터별 환경에 따라 지원 여부가 달라질 수 있습니다.

PRIVACY BY DEFAULT

원본과 프로젝트는 내 기기에 보관

Shortform Studio는 로컬 우선 앱입니다. 원본 전체 영상 파일과 생성 결과·CapCut 프로젝트는 이 컴퓨터에서 처리하고 보관하도록 설계했습니다.

AI 분석을 켜면 장면 분석에 필요한 일부 프레임과 분석 텍스트가 사용자가 설정한 OpenAI API로 전송됩니다. 해당 API 계정 사용량에 따라 요금이 발생할 수 있습니다. 웹 페이지는 영상이나 API 키를 수집하지 않습니다. 웹 호스팅 사업자는 서비스 보안 목적으로 방문자의 IP 주소 등 연결 정보를 처리할 수 있습니다.
